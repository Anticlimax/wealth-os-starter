# 公开版与私有资料

本仓库是重新构建的通用模板，初始历史只含公开代码、文档、虚构示例与测试。没有携带源项目的账本、报告、截图、归档、策略迁移、真实行情历史、个人金额、机器路径、远程部署信息、密钥或 Git 对象。

## 维护时检查

1. 私人资料只放 data/、private/、backups/、scratch/；生成结果放 output/。
2. 文档、测试、PR、截图只使用独立虚构数据，保留显著的演示标签。
3. 提交前运行 `python3 scripts/check_public.py`，查看 `git diff --cached`。
4. 扫描器检测常见密钥、机器路径及不该跟踪的数据目录，不可能判断任意自然语言里的私人事实。公开前仍需人工逐文件复查。
5. `.gitignore` 不会取消已跟踪文件，也不阻止手动复制敏感内容。不要使用 `git add -f` 上传个人资料。

## 运行与分享

数据在本地以明文存放。根据设备环境选择文件权限、磁盘加密与独立备份。公开仓库不应承担私人账本备份；另用私有且受控的存储。

分享截图前切换到 demo。公开示例目录只含合成资料。不要把 output/personal 的快照当成网站静态资源发布：它包含完整头寸、余额与目标信息。

发现公开仓库误含私人数据时，先限制继续传播并告知维护者；若涉及令牌，及时撤销。删除当前文件不能清除 Git 历史或已有副本。不要在公开 issue 中再次粘贴泄露内容。
